## 8. Куда класть VK API и VK ID (секреты)

Токен и ID в репозитории не хранятся. Скрипт ищет их в трёх местах
(`tools/vk-ads-create.js:8-10`, `readToken()` — строки 47–53).

| Что это | Где взять | Куда положить |
|---|---|---|
| `client_id` — VK ID приложения | ads.vk.ru → Настройки → Доступ к API | переменная `VK_ADS_CLIENT_ID` или флаг `--client-id` |
| `client_secret` | там же, показывается один раз и живёт 10 минут | переменная `VK_ADS_CLIENT_SECRET` или флаг `--client-secret`; **нигде не сохранять** |
| `access_token` — сам API-ключ | выдаётся обменом client_id + client_secret | файл `%USERPROFILE%\.vk-ads-token` (одна строка), переменная `VK_ADS_TOKEN` или строка `access_token = …` в файле реквизитов |

Токен живёт 24 часа; если не обновлять месяц — VK его удаляет.

### Файл реквизитов: Client ID + Client secret + access_token в одном месте

Если удобнее держать всё в одном файле, скрипт читает его сам. Порядок поиска:
`--cred-file <путь>` → переменная `VK_ADS_CRED_FILE` → `%USERPROFILE%\.vk-ads-credentials` → `D:\apivk.txt`.

Формат — строки «ключ = значение» (допускается `:`), `#` — комментарий:

```text
Client ID = 1234567890abcdef
Client secret = 0123456789abcdef...
access_token = vk1.a...
```

Команда `node tools\vk-ads-create.js token --save` берёт ID и секрет из файла,
обменивает их на токен и **дописывает** строку `access_token`, не затирая остальные.
Файл лежит вне репозитория, поэтому в сборку расширения и в git не попадает.

### Порядок действий (PowerShell, Windows)

```powershell
# 1. ID и секрет — только в переменные окружения текущей сессии
$env:VK_ADS_CLIENT_ID     = 'ваш client_id'
$env:VK_ADS_CLIENT_SECRET = 'ваш client_secret'

# 2. Обменять на токен и сохранить файл вне проекта
node tools\vk-ads-create.js token --save

# 3. Проверить, что токен жив
node tools\vk-ads-create.js check
```

Файл `C:\Users\<пользователь>\.vk-ads-token` лежит **вне** `D:\projects\market-sniper`,
поэтому не попадает ни в сборку расширения, ни в git, ни в UI.

Постоянная переменная пользователя (если файл не нужен):

```powershell
[Environment]::SetEnvironmentVariable('VK_ADS_TOKEN', '<токен>', 'User')
```

### Что нельзя

- вставлять токен и секрет в `promo/*.md`, `extension/*`, `tools/vk-ads-campaign.json`;
- отправлять их в чат, в скриншоты, в переписку с подрядчиками;
- хранить `client_secret` — он одноразовый, после обмена не нужен.

`client_id` секретом не является, но и его лучше держать в переменной окружения,
а не в файлах проекта.
