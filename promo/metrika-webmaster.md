## 1. Метрика: создать 10 целей (5 минут)

Метрика → выбрать счётчик `114252289` → **Настройка** (шестерёнка) → **Цели** → **Добавить цель**.

Тип цели — **JavaScript-событие**. Идентификатор копировать ровно как в таблице
(латиница, нижнее подчёркивание, без пробелов и заглавных букв). Название — любое, для себя.

| Идентификатор | Название для отчёта |
|---|---|
| `download` | Скачивание расширения |
| `buy` | Переход на оплату |
| `buy_month` | Переход на оплату: месяц |
| `buy_year` | Переход на оплату: год |
| `pay_online` | Клик «Оплатить онлайн» |
| `mail_confirm` | Письмо с подтверждением оплаты |
| `max_click` | Переход в MAX |
| `store_click` | Переход в каталог Edge |
| `calc` | Расчёт в калькуляторе |
| `faq_open` | Раскрытие вопроса FAQ |

После создания: **Цели** → у каждой должен быть статус «Работает» (или «Активна»).
Проверка: откройте сайт, нажмите «Скачать» — через 10–15 минут в отчёте «Конверсии» появится `download`.

Чего не делать:
- не менять номер счётчика в `site/js/metrica.js`;
- не создавать цели с русскими идентификаторами (`скачивание`) — код отправляет латиницу;
- не включать «Вебвизор», пока не правили политику конфиденциальности (в коде он выключен).

В настройках счётчика поле «Адрес сайта» должно быть `sniper.gadget-nakhodki.ru`.
Часовой пояс влияет только на отчёты — ставьте свой.

## 2. Вебмастер: добавить сайт (3 минуты + ожидание)

1. `webmaster.yandex.ru` → **Добавить сайт** → вписать `https://sniper.gadget-nakhodki.ru/`.
2. Откроется «Права на сайт». Выберите способ **Мета-тег** — он самый простой и не требует доступа к DNS.
3. Метатег уже вставлен в `index.html`: `<meta name="yandex-verification" content="70fe80bdd8e22cef">`
   (коммит `eccc50f`), на живом сайте проверен. Просто нажмите **«Проверить»**.
4. Если выбран способ DNS — добавьте TXT-запись: `Name: sniper`, `Content: yandex-verification: 70fe80bdd8e22cef`,
   Proxy — **DNS only**. Подойдёт любой из двух способов, код подтверждения один и тот же.

Альтернатива, если хотите без коммитов (DNS-запись в Cloudflare):
`Cloudflare → DNS → Add record → Type TXT`, `Name: sniper`,
`Content: yandex-verification: <строка из Вебмастера>`, Proxy — **DNS only**.

### После подтверждения прав

1. **Индексирование → Файлы Sitemap** → добавить `https://sniper.gadget-nakhodki.ru/sitemap.xml`.
   Файл уже отдаёт 200 и содержит все страницы.
2. **Индексирование → Переобход страниц** → по очереди добавить:
   `https://sniper.gadget-nakhodki.ru/`,
   `https://sniper.gadget-nakhodki.ru/kalkulyator-pribyli.html`,
   `https://sniper.gadget-nakhodki.ru/buy.html`,
   `https://sniper.gadget-nakhodki.ru/offer.html`.
   Лимит — 1–2 адреса в день, не все сразу: переобход не бесплатный по квоте.
3. **Регион** → указать регион продаж (тот, где реально ищут ваши клиенты; влияет на региональную выдачу).
4. **Быстрые ссылки** — появятся в настройках после первых показов; выбрать до 4:
   «Калькулятор прибыли», «Цена», «Установка», «Оплата».
5. **Диагностика** — раз в неделю проверять ошибки. Первые данные по запросам — через 3–7 дней.

Чего не делать:
- не добавлять сайт сразу в двух видах (`http://` и `https://`, с `www` и без) — только `https://sniper.gadget-nakhodki.ru/`;
- не удалять `Sitemap:` из `robots.txt` — Вебмастер читает его оттуда;
- не менять `canonical` на страницах: он уже абсолютный и правильный.
