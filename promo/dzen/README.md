# Материалы для Дзена

Публичного API для публикации в Дзене нет: канал ведётся через **Дзен-студию** (руками) либо
через **«Дзен для медиа»** — Дзен забирает публикации с сайта по размеченной RSS-ленте.
Поэтому здесь лежат готовые к вставке тексты, а не скрипты публикации.

| Файл | Что это |
|---|---|
| `article-01-pribyl-na-kartochke.md` | Статья №1: разбор прибыли на карточке Маркета + как работает расширение. В шапке — заголовок, подзаголовок, теги, обложка; в конце — чек-лист публикации |
| `article-02-cena-bez-ubytka.md` | Статья №2: цена без убытка — формулы, разбор по комиссиям 32–53%, реклама в цене, проверка скидки 5/10/15%, чек-лист перед сменой цены |

## Как опубликовать статью №1 (около 5 минут)

1. Откройте файл статьи, скопируйте блок «Метаданные» себе (заголовок, подзаголовок, теги).
2. Дзен-студия канала → «Создать публикацию» → «Статья».
3. Вставьте текст начиная с раздела «Почему цена в карточке ничего не говорит о вашей прибыли».
   Шапку файла и чек-лист не копируйте.
4. Визуальный редактор Дзена не понимает markdown: `##` замените стилем «Заголовок 2»,
   `**текст**` — жирным. Абзацы, списки и `—` переносятся нормально.
5. Картинки вставьте в помеченных точках `[ИЛЛЮСТРАЦИЯ N]` через кнопку «Изображение»:
   - `site/img/badge.png` — плашка с прибылью на карточке;
   - `site/img/popup.png` — окно расширения.
   Подписи к картинкам берите из текста.
6. Обложка: `promo/vk-ads/creative-1080x1080.png` (квадрат) или
   `promo/vk-ads/creative-1080x607.png` (горизонталь).
7. Ссылки оставьте с UTM — иначе источник трафика не будет виден в Метрике
   (`utm_source=dzen&utm_medium=article&utm_campaign=article-01`).
8. Опубликуйте и проверьте через сутки: показы, дочитывания, переходы на сайт в Метрике
   (цели `download`, `buy`, `calc`).

## Правила, чтобы статья не попала под ограничения

- без обещаний дохода, «гарантий», «заработка из воздуха»;
- без чужих скриншотов и логотипов маркетплейса в качестве своих;
- цифры в примере — из демо-карточки, так и написано; не выдавайте их за статистику рынка;
- ограничения продукта перечислены прямо в тексте — это снижает риск жалоб и повышает доверие.
