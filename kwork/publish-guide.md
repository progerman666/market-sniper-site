# Как опубликовать кворки в кабинете Kwork

> Публикация возможна только вручную через веб-кабинет: у Kwork нет публичного API. Ниже — порядок действий и поля, куда вставлять тексты из этого пакета.

## Подготовка (10 минут до публикации)

1. Открой `kwork/profile.md` и вставь в профиль заголовок и блок «О себе».
2. Проверь аватар: нейтральное фото или иконка, без чужих логотипов и цен.
3. Сделай 2–3 скриншота для портфолио: окно запуска `pc-diag`, файл Excel с данными, сводка/график.

## Шаг 1. Профиль

1. Войди в кабинет → **Настройки профиля** (или «Профиль»).
2. Поле специализации/заголовка — вставь строку из `profile.md`.
3. Поле «О себе» / «Описание» — вставь текст из `profile.md`.
4. Навыки — добавь 10–15 тегов, не больше: размытие вредит поиску.
5. Сохрани. Проверь, что текст не обрезан по лимиту поля.

## Шаг 2. Публикация кворка №1 (1 000 ₽)

1. Кабинет → **Мои кворки** → **Создать кворк**.
2. Категория: **Разработка и IT** → направление, ближайшее к «парсинг / скрипты / автоматизация». Если нужной подкатегории нет, выбирай «Разработка и IT» и ставь точные теги в названии.
3. Название — из `kworks/01-mini-1000.md`.
4. Описание — блок в тройных кавычках из того же файла.
5. Цена: **1 000 ₽**.
6. Срок: **1 день**.
7. Опции — добавь из таблицы «Опции» (каждая опция со своей ценой и сроком).
8. Обложка: скриншот запуска или таблицы Excel, без логотипов маркетплейсов.
9. Теги: Python, API, парсинг данных, Excel, автоматизация.
10. Требования к заказчику — блок «Что нужно от клиента» из файла.
11. Отправь на публикацию и дождись модерации.

## Шаг 3. Публикация кворка №2 (4 000 ₽)

Повтори шаг 2 с файлом `kworks/02-parser-4000.md`:
- цена **4 000 ₽**, срок **3 дня**;
- добавь три пакета: 4 000 / 6 500 / 9 000 ₽;
- опции — 6 штук из таблицы;
- в описании оставь блок «Чего не делаю» — он снимает половину неадекватных заказов.

## Шаг 4. Портфолио

1. Раздел портфолио → добавь кейс из `portfolio/demo-case.md` (кейс 1: `pc-diag`).
2. Приложи 2 скриншота к кейсу.
3. Второй кейс (`telegram-bot-dwh`) добавь, если модерация пропускает текст про ETL без ссылок.

## Шаг 5. Первые заявки

1. Раздел **Биржа проектов** → фильтры: «парсинг», «сбор данных», «выгрузка в Excel», «автоматизация».
2. Откликайся на 10–20 проектов в день. Шаблон отклика ниже.
3. В отклике — конкретика по задаче заказчика, не общее «готов сделать».

### Шаблон отклика на проект

```
Здравствуйте! По вашей задаче:

1. Уточню 2 вопроса: какой источник данных и какие поля нужны в итоге.
2. Соберу через официальный API (без обхода защит) и отдам .xlsx с готовыми колонками.
3. Срок — 1–3 дня, в зависимости от объёма. Пришлю пример файла на первых 20 строках до полной сборки.

Работаю с Ozon Seller API, WB API и открытыми страницами. Если ключей API нет — помогу получить по инструкции.
```

## Проверки перед отправкой на модерацию

- Нет ссылок (`http`, домены, `t.me`), нет почты и телефона, нет «@ник».
- Нет слов «гарантирую», «100%», «обход капчи», «любой сайт без ограничений».
- Цена не ниже 500 ₽ (минимум площадки).
- Срок указан и реалистичен: 1 день — мини, 3 дня — полный парсер.
- В описании есть границы: что НЕ входит в работу.

## Что я не могу сделать и почему

- **Опубликовать за тебя через API** — у Kwork нет публичного API (проверено: `kwork.ru/api` → 404).
- **Зайти в кабинет** — для этого нужны твой логин и пароль, а также обход антибота. Это нарушение правил площадки и риск блокировки аккаунта, поэтому я этого не делаю.
- **Автоматизировать через браузер** — технически можно написать локальный скрипт, который ты запускаешь у себя, но это серая зона по правилам Kwork и хрупко (капча, смена вёрстки). Если решишь — скажи, напишу, но запускать будешь сам и на свой риск.

## Порядок, который даёт результат

Профиль → кворк №1 → кворк №2 → портфолио → отклики. Не наоборот: без откликов кворки с нулевым рейтингом почти не показываются.
