# Кворк 2 — полный парсер, 4 000 ₽

Основной кворк с нормальной маржой. Цель — 2–3 заказа в месяц по 4 000 ₽ плюс опции.

## Название

```
Сделаю парсер маркетплейса с .exe и выгрузкой в Excel
```

## Описание

```
Сделаю сборщик данных с маркетплейса: клиент запускает .exe одной кнопкой и получает свежий Excel.

Что входит в базовый пакет:
— сбор данных по одному источнику через официальный API;
— до 5 000 товаров за запуск;
— .exe для Windows: ничего устанавливать не нужно, Python не требуется;
— файл .xlsx с согласованными колонками;
— лог работы и понятные ошибки на русском;
— инструкция: как запустить, где взять ключи, что делать при ошибке;
— 14 дней бесплатных правок, если API изменился и сбор перестал работать.

Пакеты:
— Базовый, 4 000 ₽, 3 дня: 1 источник, до 5 000 товаров, .exe + Excel.
— Стандарт, 6 500 ₽, 5 дней: 2 источника, выгрузка в Google Sheets, запуск по расписанию.
— Премиум, 9 000 ₽, 7 дней: 3 источника, мониторинг с уведомлениями, установка на ваш компьютер, 1 месяц поддержки.

Чего не делаю:
— обход капчи, антиботов и защит сайтов;
— сбор персональных данных покупателей;
— изменение цен, остатков и любые действия в вашем кабинете;
— работу с чужими кабинетами без ключей.

Что нужно от вас: ключи API, список товаров или магазин, перечень полей, куда складывать результат. Если ключей нет — помогу получить по инструкции, это платная опция.

Сроки: 3 дня базовый, 5 дней стандарт, 7 дней премиум. Отсчёт с момента, когда получены ключи и согласованы поля.

Перед заказом напишите источник и задачу — скажу, реализуемо ли это через API или потребуется другой подход.
```

## Что нужно от клиента

1. Источник и тип доступа: официальный API / открытые страницы.
2. Ключи и подтверждение, что у клиента есть права на эти данные.
3. Объём: количество товаров, частота сбора.
4. Формат: колонки, сортировка, отдельные листы по категориям.
5. Куда доставлять: файл на компьютере, Google Sheets, Telegram.

## Как сдаём работу (приёмка)

1. Присылаю пример файла на 20–30 строках.
2. Клиент подтверждает колонки и структуру.
3. Собираю полный объём, отдаю `.exe` + README + пример файла.
4. Клиент запускает у себя, присылает скриншот результата.
5. Правки по согласованному ТЗ — в рамках 14 дней; новые хотелки — отдельная опция.

## Границы ответственности (проговорить до заказа)

- Если API маркетплейса меняет формат — правлю бесплатно 14 дней, дальше по опции поддержки.
- Если клиент выдал ключи без нужных прав — это не баг, а настройка доступа на стороне клиента.
- Если данные запрещены к сбору правилами площадки — берусь только за легальные источники, иначе отказываюсь.
