# Кворк 1 — мини-услуга, 1 000 ₽

Входной кворк для первых 2–3 отзывов. Цель — быстро, честно, без правок. После 3 отзывов цену поднять до 1 500 ₽, после 5 — до 2 000 ₽.

## Название

```
Соберу данные из маркетплейса через API и выгружу в Excel
```

## Описание

```
Соберу данные по вашим товарам через официальный API маркетплейса и отдам готовый файл Excel.

Что входит:
— подключение к API по вашим ключам (Ozon Seller API, WB API или Я.Маркет);
— сбор до 1 000 товаров по вашему списку артикулов или по вашему магазину;
— выгрузка в .xlsx с понятными колонками: артикул, название, цена, остатки, рейтинг, количество отзывов, ссылка;
— короткая инструкция, как запустить сбор повторно.

Как работаем:
1. Вы присылаете ключи API и список товаров (или доступ к своему магазину по ключам).
2. Я проверяю доступ тестовым запросом и согласовываю поля.
3. Собираю данные и отдаю файл.
4. Вы проверяете 5–10 строк и подтверждаете приёмку.

Срок: 1 день с момента получения ключей и списка.

Что важно знать:
— работаю только через официальные API и открытые страницы, без обхода капчи и антиботов;
— ключи API нужны ваши: в чужой кабинет без них я не зайду;
— если ключей нет, помогу получить их по инструкции — это отдельная опция;
— не собираю персональные данные покупателей и не меняю ничего в вашем кабинете.

Если нужен не один разовый файл, а регулярное обновление — есть отдельный кворк с полным парсером.
```

## Что нужно от клиента (заполнить в переписке)

1. Какой маркетплейс и какой API.
2. Ключи: `Client-Id` + `Api-Key` (Ozon) или токен (WB).
3. Список товаров: артикулы/ссылки или магазин целиком.
4. Какие поля нужны (цена, остатки, рейтинг, отзывы, позиция в поиске).
5. Куда отдать результат: файл Excel или таблица.

## Ответ на частые возражения

- **«А почему так дёшево?»** — Это разовый сбор по одному источнику. Регулярный мониторинг и несколько площадок — другой объём, он дороже.
- **«Данные не устареют?»** — Файл — снимок на момент сбора. Для актуальности есть опция автообновления или отдельный кворк с мониторингом.
- **«Ключи давать страшно»** — Ключи не покидают вашу переписку и не сохраняются у меня дольше, чем нужно для сборки. Можно выдать ключ с ограниченными правами только на чтение.
