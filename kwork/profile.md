## О себе (описание профиля)

```
Здравствуйте! Я Python-разработчик. Собираю данные с маркетплейсов через официальные API и выгружаю в Excel или Google Sheets — без ручных выгрузок и без обхода защит.

Что делаю:
— сбор данных по Ozon Seller API, WB API и открытым страницам сайтов;
— выгрузка в Excel/Google Sheets с готовой структурой: название, цена, остатки, рейтинг, отзывы, ссылка;
— сборка .exe, чтобы запускать сбор одной кнопкой без установки Python;
— простые сводки по данным: динамика цен, топ товаров, сравнение с конкурентами.

Почему ко мне:
— работаю только через официальные API и открытые страницы, без обхода капчи и антиботов — данные не отваливаются через неделю;
— отдаю читаемый код и инструкцию, ошибки в логах на русском;
— 14 дней бесплатно правлю, если что-то сломалось из-за изменений API.

Чего не делаю: обход защиты, сбор персональных данных, работа в чужих кабинетах без ключей.

Перед заказом напишите источник и нужные поля — скажу, что реально и сколько это стоит по времени.
```

## Чек-лист публикации профиля

1. Заголовок — без «парсинга» в смысле «обход защиты», только «сбор данных».
2. Описание — без контактов и ссылок. Проверить на слова «гарантирую», «100%», «любые сайты».
3. Навыки — не более 15 тегов, иначе размывается поиск.
4. Портфолио — приложить кейс из `portfolio/demo-case.md` и 1–2 скриншота результата (таблица Excel, окно запуска).
5. Цены в профиле не указывать — они живут в кворках.

## Что проверить при вставке

- Лимит длины поля «О себе» в кабинете (если текст не влезает — резать блок «Почему ко мне», он повторяется в кворках).
- Нельзя упоминать маркетплейсы в заголовке, если модерация сочтёт это рекламой бренда — тогда использовать «сбор данных с торговых площадок через API».
- Аватар и обложка: без чужих логотипов, без обещаний «доход», без цен.
