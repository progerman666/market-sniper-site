## Кейс 1. Диагностика Windows за 60 секунд (`pc-diag`)

**Задача.** Пользователь видит, что компьютер «тормозит», но стандартные средства Windows показывают либо слишком мало (Диспетчер задач), либо слишком много (Event Viewer, WMI, smartctl по отдельности). Нужен один отчёт, который сам говорит, что не так и что делать.

**Решение.**
- Сборщики данных: система, нагрузка в реальном времени, диски, SMART, сеть, автозагрузка, службы, Event Log, размеры папок.
- Слой правил: 15+ детерминированных проверок (износ SSD, заполнение диска, потеря пакетов, ошибки в журнале, раздутая автозагрузка).
- Опциональное объяснение через локальную LLM (Ollama) — модель только объясняет, ничего не выполняет.
- Сборка `.exe` через PyInstaller: клиент запускает без установки Python, есть консольный режим и JSON-вывод.
- Автосборка релизов через GitHub Actions по тегу, установщик на Inno Setup.

**Результат.** Отчёт за 60 секунд вместо ручного обхода трёх инструментов; инструмент read-only, ничего не меняет в системе; готовые сборки и публичный релиз; сайт-лендинг; лицензия MIT.

**Что это доказывает для заказа.** Умею собирать данные с разных источников, писать правила анализа, упаковывать Python в `.exe` для нетехнического пользователя и вести проект до релиза.

## Кейс 2. ETL и мини-хранилище вокруг Telegram-бота (`telegram-bot-dwh`)

**Задача.** Telegram-бот собирал заявки в SQLite. Данные копились, но аналитики не было: нельзя посмотреть динамику по дням, топ активных пользователей, категории обращений.

**Решение.**
- Трёхслойное хранилище в Greenplum: `raw → staging → marts`.
- ETL на Python: pandas, SQLAlchemy, psycopg2, батчевая загрузка.
- Трансформации через dbt: модели, тесты, документация.
- Оркестрация через Airflow: расписание, зависимости, ретраи.
- Тесты качества данных: `unique`, `not_null`, `accepted_values`.

**Результат.** Готовые витрины `dm_daily_stats` и `dm_user_activity` с динамикой по дням и топом пользователей; воспроизводимое окружение в Docker Compose; схема архитектуры и скриншоты.

**Что это доказывает для заказа.** Умею не только собрать данные, но и привести их в вид, пригодный для анализа: очистка, слои, тесты, регулярный запуск.
