# Сайт «Маркет-Снайпер» для обычного хостинга (Ru-Center, PHP)

Этот архив — готовый `public_html`: лендинг, страница оплаты, документы и PHP-API выдачи ключей.
Cloudflare не используется, всё работает на российском хостинге.

## Структура

```
index.html        главная (hero, что показывает, как работает, цена, установка, FAQ)
kalkulyator-pribyli.html  калькулятор прибыли и таблица комиссий (SEO-страница)
buy.html          оплата: онлайн через ЮKassa + резервный перевод по СБП
thanks.html       «оплата принята» — страница возврата ЮKassa (noindex)
privacy.html      политика конфиденциальности (нужна для ревью в Edge)
offer.html        публичная оферта
404.html          страница «не найдено» (GitHub Pages отдаёт её автоматически)
styles.css        стили
js/metrica.js     Яндекс.Метрика и цели (номер счётчика — MS_METRIKA_ID)
js/calc.js        расчёт прибыли в калькуляторе
sitemap.xml       карта сайта для Вебмастера и Search Console
config/selectors.json  селекторы карточки для расширения (обновляются без перевыпуска)
img/              скриншоты расширения и иконка
download/         market-sniper-0.4.3.zip — то, что скачивает покупатель
api/
  plans.php       GET  — цены (их читает и лендинг, и расширение)
  pay.php         POST — создать платёж (ЮKassa или ЮMoney) и вернуть ссылку на оплату
  go.php          GET  — форма быстрой оплаты ЮMoney (сумма и метка берутся из заказа)
  webhook.php     POST — уведомление провайдера: проверка, выдача ключа, письмо
  issue.php       POST — выдать ключ вручную (заголовок X-Admin-Secret)
  check.php       GET  — проверка/отзыв ключа: ?key=MS1...
  admin.php       страница ручной выдачи ключа (пароль = admin_secret)
  config.php      настройки: пароль, тарифы, ЮKassa, почта (закрыт .htaccess)
  keys/private.pem   приватный ключ подписи (закрыт .htaccess)
  data/           журналы выдачи, платежи, письма, revoked.json (закрыт .htaccess)
.htaccess         HTTPS-редирект, запрет листинга
robots.txt
```

## Загрузка на Ru-Center (5 шагов)

1. Панель Ru-Center → **Хостинг** → ваш домен → «Файловый менеджер» (или подключитесь по FTP/SFTP:
   логин и пароль там же, в разделе «Хостинг → Доступ по FTP»).
2. Откройте каталог сайта: обычно `/www/<домен>/public_html` или `/public_html`.
3. Загрузите `rucenter-site.zip` и распакуйте его **в корень** `public_html` (чтобы `index.html` лежал рядом с папкой `api`, а не внутри ещё одной папки).
4. В панели: **PHP → версия 8.0 или выше**, расширение `openssl` включено (по умолчанию включено).
5. Откройте `https://ваш-домен/api/plans.php` — должен вернуться JSON с двумя тарифами. Если вернулся код PHP текстом, значит PHP не включён для каталога.

### Обязательно перед публикацией

- [ ] В `api/config.php` заменить `admin_secret` на свой пароль (или задать переменную окружения `MS_ADMIN_SECRET`).
- [ ] Для онлайн-оплаты задать `MS_YOOKASSA_SECRET_KEY` (см. раздел «Онлайн-оплата») и прописать
      `https://<домен>/api/webhook.php` в ЮKassa → Интеграция → HTTP-уведомления (`payment.succeeded`, `payment.canceled`).
- [ ] Проверить почту: `MS_MAIL_FROM` должен быть на вашем домене, иначе письма с ключами уйдут в спам.
- [ ] При желании перегенерировать ключ подписи: новая пара ECDSA P-256, приватный ключ → `api/keys/private.pem`, публичный → `MS_LICENSE.PUBLIC_KEY_B64` в `extension/license.js` (иначе старые ключи перестанут проверяться).
- [ ] В `index.html`, `buy.html`, `privacy.html`, `offer.html` заменить: `hello@example.ru`, телефон для СБП, ФИО, ИНН, название банка.
- [ ] В `extension/license.js` указать `MS_PRICING.purchaseUrl = 'https://ваш-домен/buy.html'` и пересобрать zip в `download/`.
- [ ] Проверить загрузку архива: `https://ваш-домен/download/market-sniper-0.4.3.zip`.

## Вариант «поддомен на существующем домене» (0 ₽)

1. Панель Ru-Center → **Домены** → ваш домен → «Поддомены» / «Управление поддоменами».
2. Добавить поддомен, например `sniper` → каталог **`/www/<домен>/public_html/sniper`** → сохранить.
   Подождать 5–30 минут, пока обновится DNS.
3. Загрузить содержимое `site/` в этот каталог (проще тем же `deploy-rucenter.ps1`,
   указав `-RemotePath "/www/<домен>/public_html/sniper"`, либо распаковать zip в файловом менеджере).
4. В разделе **SSL** включить бесплатный Let's Encrypt для поддомена.
5. Проверить `https://sniper.<домен>/api/plans.php` — должен вернуться JSON.

Все ссылки на сайте относительные, поэтому сайт одинаково работает и в корне `public_html`, и в подпапке.

### Переезд на купленный домен (когда будет)

```powershell
cd D:\projects\market-sniper
.\set-domain.ps1 -Domain "sniper-market.ru" -Email "hello@sniper-market.ru"
```

Скрипт сам поправит ссылку на покупку в расширении (`license.js`), canonical в лендинге, e-mail,
пересоберёт `dist\market-sniper-0.4.3.zip` и `dist\site-rucenter.zip` и положит свежий архив расширения в
`site\download\`. После этого — залить сайт на новый домен и обновить расширение в браузере/магазине.

Чтобы старый поддомен не терял переходы, добавьте в его `.htaccess`:

```apache
Redirect 301 / https://sniper-market.ru/
```

## Оплата и выдача ключа

### Онлайн-оплата: ключ приходит сам

Цепочка: `buy.html` → `api/pay.php` создаёт платёж в ЮKassa → покупатель платит картой или по СБП →
ЮKassa вызывает `api/webhook.php` → платёж перепроверяется через API → `ms_issue()` подписывает ключ →
письмо покупателю и копия администратору. Обычно 10–30 секунд после оплаты.

Что нужно один раз настроить:

1. Магазин в ЮKassa (самозанятому подходит, при регистрации указать НПД).
2. **Shop ID** уже прописан в `api/config.php` (`4100119685733916`); при смене магазина — заменить.
3. **Secret key**: ЮKassa → Настройки → API-ключи → «Выпустить ключ». Хранить в переменной окружения
   `MS_YOOKASSA_SECRET_KEY` (на хостинге — через `.htaccess`/`SetEnv` или в панели; в крайнем случае
   вписать в `api/config.php` — файл закрыт `.htaccess`).
4. В ЮKassa → Интеграция → **HTTP-уведомления**: URL `https://<домен>/api/webhook.php`, события
   `payment.succeeded` и `payment.canceled`. Подпись не нужна: webhook сам запрашивает платёж через API
   и сверяет сумму, поэтому подделать уведомление нельзя.
5. Страница возврата после оплаты — `https://<домен>/thanks.html`; адрес определяется из запроса
   автоматически, при нестандартной схеме задаётся `MS_RETURN_URL` или `MS_SITE_URL`.
6. Почта: `MS_MAIL_FROM` должен быть на вашем домене (например `no-reply@<домен>`), иначе письма с ключами
   попадут в спам. Проверка без отправки — `MS_MAIL_TRANSPORT=log` (письма пишутся в `api/data/mail.log`).

> **Важно про два разных продукта.** `4100119685733916` — это номер **кошелька ЮMoney**
> (16 цифр, начинается на `41001`), а не shopId. ShopId ЮKassa выглядит как `100500` и живёт
> в кабинете `yookassa.ru` → «Настройки» → «API-ключи» (в части интерфейсов — «Интеграция» → «Ключи API»).
> У кошелька никаких API-ключей нет — для него ниже есть отдельный, более простой вариант.

### Вариант без ЮKassa: приём на кошелёк ЮMoney

Кошельку не нужны ни shopId, ни secret key — только номер кошелька и секрет уведомлений.

1. `yoomoney.ru` → **Настройки** → **HTTP-уведомления**: указать URL `https://<домен>/api/webhook.php`
   и придумать секретный ключ (он же `MS_YOOMONEY_SECRET`). Там есть кнопка «Протестировать».
2. Задать переменные `MS_YOOMONEY_RECEIVER=4100119685733916` и `MS_YOOMONEY_SECRET=<секрет>`.
   Если секрет ЮKassa не задан, провайдер выберется сам (`provider=auto`); принудительно — `MS_PROVIDER=yoomoney`.
3. Покупатель нажимает «Оплатить» → `api/pay.php` создаёт метку `MS-…` → `api/go.php` открывает форму
   `yoomoney.ru/quickpay/confirm` с суммой и меткой → после перевода приходит уведомление →
   подпись `sign` (HMAC-SHA256) проверяется → ключ уходит письмом.
4. Комиссия удерживается с получателя (карта ~3%, кошелёк ~1%), поэтому на кошелёк приходит меньше суммы.
   Скрипт принимает оплату не ниже 95% цены (`MS_YOOMONEY_MIN_RATIO`), иначе пишет вам письмо и ключ не выдаёт.
5. Чек НПД в этом варианте пробивается вручную в «Мой налог».

Проверка: `node _scrape\test\test-yoomoney.js` — 22 проверки (форма, подпись, ключ, повтор,
заниженная сумма, код протекции, неизвестная метка).

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `MS_PROVIDER` | `auto` | `yookassa`, `yoomoney` или автоопределение |
| `MS_YOOMONEY_RECEIVER` | `4100119685733916` | номер кошелька для приёма переводов |
| `MS_YOOMONEY_SECRET` | — | секрет HTTP-уведомлений кошелька |
| `MS_YOOMONEY_PAYMENT_TYPE` | `AC` | `AC` — карта, `PC` — кошелёк |
| `MS_YOOMONEY_MIN_RATIO` | `0.95` | минимальная доля суммы с учётом комиссии |
| `MS_YOOKASSA_SHOP_ID` | — | shopId магазина ЮKassa |
| `MS_YOOKASSA_SECRET_KEY` | — | секретный ключ API (обязателен для онлайн-оплаты) |
| `MS_SITE_URL` | вычисляется из запроса | базовый адрес сайта для писем и redirect |
| `MS_RETURN_URL` | `<сайт>/thanks.html` | куда вернуть покупателя после оплаты |
| `MS_SEND_RECEIPT` | `1` | передавать чек в запросе платежа |
| `MS_MAIL_FROM` / `MS_MAIL_ADMIN` | `no-reply@…` / `goinslims@gmail.com` | отправитель и копия |
| `MS_MAIL_TRANSPORT` | `mail` | `log` — не отправлять, писать в журнал |
| `MS_PAY_RATE_LIMIT` | `10` | сколько платежей можно создать с одного IP в час |

Журналы: `api/data/payments.log` (создание, оплата, отмена, ошибки), `api/data/mail.log` (письма),
`api/data/issued.log` (ключи), `api/data/payments/<id>.json` (ключ по каждому платежу — для повторной отправки).

Проверка без реальных денег: `node _scrape\test\test-yookassa.js` — 29 проверок на моке ЮKassa
(чек, повтор без чека, идемпотентность, подмена суммы, отмена, неизвестный платёж).

### Ручная выдача (перевод по СБП, возврат, повторная отправка)

1. Открыть `https://ваш-домен/api/admin.php`, ввести пароль, выбрать тариф, вписать номер заказа или почту → получить ключ.
2. Отправить ключ покупателю письмом, пробить чек в «Мой налог».
3. Журнал выдачи: `api/data/issued.log`. Чтобы аннулировать ключ — добавить его `id` в `api/data/revoked.json` (массив строк), тогда `check.php` начнёт отвечать `valid: false`.

Чек НПД: автоматически его передаёт только платёжный провайдер-партнёр ФНС. Если ЮKassa для вашего
магазина уже передаёт чеки в «Мой налог» — делать ничего не нужно; если нет, пробейте чек вручную
по письму о платеже.

## Аналитика и Яндекс.Вебмастер (чтобы росли клики)

### 1. Яндекс.Метрика

1. `metrika.yandex.ru` → «Добавить счётчик»: имя «Маркет-Снайпер», тип «Сайт», домен `sniper.gadget-nakhodki.ru`.
2. Номер счётчика (8 цифр) впишите в `js/metrica.js` → `var MS_METRIKA_ID = 0;` (вместо нуля).
3. Создайте цели типа «JavaScript-событие» с идентификаторами:
   `download`, `buy`, `buy_month`, `buy_year`, `pay_online`, `mail_confirm`, `max_click`, `store_click`, `calc`, `faq_open`.
   Код отправляет их сам: скачивание архива, переходы на оплату, письмо, MAX, каталог Edge, кнопка «Рассчитать», раскрытие FAQ.
4. Проверка: откройте сайт, нажмите «Скачать» — в Метрике на вкладке «Цели» конверсия появится в течение 5–10 минут.

Пока `MS_METRIKA_ID = 0`, скрипт не загружается и запросов к Яндексу нет. Политика конфиденциальности уже описывает Метрику (раздел 3) — не убирайте этот абзац.

### 2. Яндекс.Вебмастер

1. `webmaster.yandex.ru` → «Добавить сайт» → `https://sniper.gadget-nakhodki.ru/`.
2. Подтвердите права. Проще всего DNS-записью: Cloudflare → DNS → Add record → TXT, name `sniper`, value из Вебмастера (`yandex-verification: ...`). Альтернатива — HTML-тег: раскомментируйте `<meta name="yandex-verification" ...>` в `<head>` любой страницы, залейте и нажмите «Проверить».
3. «Индексирование → Файлы Sitemap» → добавьте `https://sniper.gadget-nakhodki.ru/sitemap.xml`.
4. «Индексирование → Переобход страниц» → отправьте `/`, `/kalkulyator-pribyli.html`, `/buy.html`.
5. «Регион» — укажите регион продаж, чтобы сайт участвовал в региональной выдаче.
6. «Быстрые ссылки» — когда появятся показы, выберите до 4 ссылок: «Калькулятор прибыли», «Цена», «Установка», «Оплата». Это напрямую увеличивает клики из сниппета.
7. «Диагностика» — раз в неделю проверяйте ошибки и «малополезные страницы».

### 3. Google Search Console (по желанию)

1. `search.google.com/search-console` → «Добавить ресурс» → «Префикс URL» `https://sniper.gadget-nakhodki.ru/`.
2. Подтверждение — DNS TXT или `<meta name="google-site-verification">` (место в `<head>` уже размечено комментарием).
3. «Файлы Sitemap» → `sitemap.xml`.

### 4. Что уже сделано для кликов

- Title и description переписаны под запросы «расчёт прибыли на Яндекс.Маркете», «расширение для продавца», «калькулятор прибыли».
- Новая страница `kalkulyator-pribyli.html`: калькулятор + таблица комиссий 32–53% + FAQ — под низкочастотные запросы.

- `sitemap.xml`, `robots.txt` с `Sitemap:`, `404.html`, canonical и OG-теги на всех страницах.
- Внутренние ссылки на калькулятор: меню, hero и футер каждой страницы.

## Отказоустойчивость расширения (если Маркет меняет вёрстку)

- Цена берётся по цепочке: DOM-селекторы → `meta[property="product:price:amount"]` → JSON-LD `Product.offers.price`. Магазин: блок магазина → ссылка `/business--` → JSON-LD `seller.name`. Предложения: `data-zone-data` → текст «ещё N предложений» → JSON-LD. Источники пишутся в `debug.priceSource` / `sellerSource` / `offersSource`.
- Бейдж живёт в Shadow DOM (`.ms-root`): стили страницы его не перебивают, а при удалении он возвращается через `MutationObserver`.
- `config/selectors.json` — удалённый конфиг селекторов. Расширение забирает его через background раз в 12 часов и кэширует в `chrome.storage.local`. Если файла нет или сеть недоступна — работают встроенные значения. Вёрстку можно починить без перевыпуска пакета.
- В попапе есть поле «Цена вручную» и диагностика (страница, источник цены, версия): если карточка не прочиталась, клиент всё равно считает прибыль.
- Пакет расширения пересобирается командой `.\tools\build-extension-zip.ps1` (кладёт zip в `dist\` и копию в `site\download\`).
