# Публикация в Microsoft Edge Add-ons — по шагам

Пакет: `dist\market-sniper-0.4.3.zip` (версия 0.4.2, разрешение только `storage`).
Тексты: `store\edge-listing.md`. Скриншоты: `store\screenshots\*.png` (1280×800).

## 1. Аккаунт (один раз, бесплатно)

1. Открыть https://partner.microsoft.com/ → войти личным Microsoft-аккаунтом.
2. «Регистрация» → программа **Microsoft Edge** → заполнить профиль (страна, имя, e-mail).
3. Дождаться письма об активации (обычно минуты). Оплата не нужна.

## 2. Создание расширения

1. Partner Center → **Microsoft Edge** → «Новое расширение».
2. Загрузить `dist\market-sniper-0.4.3.zip` (манифест должен быть в корне zip — так и есть).
3. Записать **Product ID** из адреса страницы `/products/<ProductId>` — он понадобится для обновлений через `publish-edge.ps1`.

## 3. Availability (доступность)

- Рынки: **Все рынки** (или Россия + СНГ, если хотите ограничить).
- Видимость: публичное.
- Дата выхода: сразу после сертификации.

## 4. Properties (свойства)

- Категория: **Productivity** (или «Инструменты для бизнеса»).
- Язык по умолчанию: **ru-RU**.
- Требования: «Не требует дополнительного ПО».

## 5. Privacy (конфиденциальность)

- «Использует ли расширение удалённый код?» — **Нет**.
- «Собирает ли персональные данные?» — **Нет** (настройки и ключ хранятся локально).
- Политика конфиденциальности: `https://sniper.gadget-nakhodki.ru/privacy.html`
- Обоснование прав — скопировать из `store/edge-listing.md`, раздел «Обоснование разрешений».

## 6. Store listing (витрина)

- Название: `Маркет-Снайпер — прибыль на карточке`
- Краткое описание: из `edge-listing.md` (до 132 символов).
- Подробное описание: оттуда же.
- Скриншоты: загрузить 3 файла из `store\screenshots\` (порядок: бейдж → окно → лендинг).
- Иконка и логотип подтянутся из пакета.
- Поисковые термины: `маркет, прибыль, калькулятор, продавец, маржа, комиссия`.

## 7. Certification notes (для ревьюеров)

Скопировать из `edge-listing.md`. Обязательно добавить рабочий e-mail для связи и, если попросят, тестовый ключ:

```powershell
node tools\issue-key.js --plan month --order "REVIEW"
```

Учтите: ключ подписывается текущим приватным ключом, поэтому он рабочий только для этой сборки. Если будете перегенерировать пару — не забудьте обновить `PUBLIC_KEY_B64` в `extension\license.js` до сборки zip.

## 8. Отправка

«Опубликовать» → проверка обычно **1–7 рабочих дней**. Если вернут с замечанием — правите, поднимаете версию (`manifest.json` → `version`) и загружаете новый zip через `publish-edge.ps1` или вручную.

## 9. После публикации

- Ссылка на каталог будет вида `https://microsoftedge.microsoft.com/addons/detail/<id>` — поставить её на лендинг кнопкой «Установить из каталога Edge» (сейчас там ручная установка).
- Раздел «Установка» на сайте упростить до одной кнопки + «если каталог недоступен, скачайте zip».
