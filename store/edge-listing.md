## Подробное описание

```
Маркет-Снайпер считает, сколько вы реально заработаете с товара на Яндекс.Маркете — прямо на странице, без таблиц и калькуляторов.

Что вы видите на карточке:
• прибыль с продажи по вашим ставкам;
• сколько забирает Маркет, сколько уходит на доставку и рекламу;
• какой процент цены остаётся вам;
• медиану цен похожих предложений и позицию вашей цены на рынке;
• минимальную цену без убытка и цену под нужную маржу;
• название магазина и количество предложений у товара.

Как считается: цена минус комиссия Маркета, минус доставка, минус реклама. Тарифы соответствуют официальной справке Маркета: кнопка «Тариф Маркета» подставляет процент по категории и оценку доставки.

Особенности:
• всё по-русски, без аббревиатур FBY/FBS/DBS — «товар на складе Маркета», «свой склад, доставка Маркета» и т.д.;
• расчёт работает офлайн: подпись ключа проверяется в браузере, данные никуда не отправляются;
• настройки хранятся только у вас в браузере;
• 7 дней полного доступа без карты и регистрации, затем остаётся базовый расчёт.

Данные со страниц не собираются и не передаются. Расширение работает только на market.yandex.ru и не аффилировано с Яндексом.
```

## Обоснование разрешений (для ревью)

- `storage` — сохранение настроек ставок (комиссия, доставка, реклама) и лицензионного ключа локально в браузере.
- `host_permissions: *://*.market.yandex.ru/*` — расширение читает цену, старую цену, название магазина и число предложений на странице товара, чтобы посчитать прибыль, и вставляет блок под ценой.
- Для медианы цен расширение открывает страницу предложений того же товара на `market.yandex.ru` (`/offers/...`) — запрос идёт только на Яндекс, результат кэшируется в браузере на 6 часов. Никакие данные никуда не отправляются и не собираются.
- Других разрешений нет: нет `tabs`, `scripting`, `downloads`, нет доступа к другим сайтам.

## Заметки для сертификации

```
Расширение не требует аккаунта и не собирает персональные данные.
Проверка: открыть любую карточку товара на https://market.yandex.ru — под ценой появится тёмный блок «Прибыль с продажи ≈ N ₽».
Пробный период 7 дней включён автоматически; ключ для проверки платных функций: <при необходимости выдать тестовый ключ командой node tools\issue-key.js --plan month --order "REVIEW">
Ошибки FailedHydrationError в консоли Маркета относятся к самому сайту и не связаны с расширением.
```

## Чек-лист отправки

1. Partner Center → Microsoft Edge → New extension → загрузить `dist\market-sniper-0.4.3.zip`.
2. Availability: Россия (можно все рынки).
3. Properties: категория «Инструменты для бизнеса», язык русский.
4. Privacy: вставить обоснование разрешений выше, указать политику конфиденциальности.
5. Store listing: название, краткое и подробное описание, 3 скриншота.
6. Certification notes: текст выше.
7. Submit. Проверка обычно 1–7 рабочих дней.
